## Entities

This is the only Entity documentation folder. Each page defines one Entity's purpose, owned state, commands, relations, runtime behavior, source files, and governing decisions.

Entity pages are written for agent discovery and implementation work. The Entity class, schema, and contract files remain the implementation source; this folder explains the ownership model agents must follow before editing code.
