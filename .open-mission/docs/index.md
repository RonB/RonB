## Open Mission Docs

These docs help operators and contributors use Open Mission. They are organized by reader need:

| Section | Use it for |
| --- | --- |
| [Tutorials](tutorials/) | Learning workflows with guided examples. |
| [How-To Guides](guides/) | Completing one concrete task. |
| [Concepts](concepts/) | Understanding product concepts in user language. |
| [Reference](reference/) | Looking up exact commands, settings, and behavior. |
| [Explanations](explanations/) | Reading background articles and design context. |

Canonical engineering authority lives in [`../knowledgebase/`](../knowledgebase/). User docs explain how to use Open Mission; the knowledgebase defines architecture and governance.
